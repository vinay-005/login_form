# 🔐 Glassmorphism Login Form

A sleek and modern **Login Form UI** built using pure HTML and CSS. This project features a premium **glassmorphism design**, social login buttons, and a clean user interface layout.

---

## ✨ Features

* 💎 Glassmorphism login card (blur + transparency)
* 🎨 Soft gradient background with watermark effect
* 🔘 Social login UI (Google & Apple)
* 📱 Responsive and centered layout
* 🧊 Smooth input focus and hover effects
* 🧾 Minimal footer with copyright

---

## 📂 Project Structure

```
login-form/

│   ├── google.png

```

## 🚀 How to Use

1. Download or clone this repository:

```
git clone https://github.com/your-username/login-form.git
```

2. Open the project folder:

```
cd login-form
```

3. Run the project:

* Simply open `index.html` in your browser
